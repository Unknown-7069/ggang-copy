②첫번째 입력칸에 <b>https://github.com/Unknown-7069/ggang-copy</b> 넣고 인스톨폴미(빨간버튼)<br>
ㄴ다시 확장프로그램 눌렀을 때 [깡갤 복사기]보이면 설치 완료! 안보이면 새로고침<br>

<b>#기본 사용방법</b><br>
①메세지 복사 : 시작위치, 종료위치에 메세지 넘버(숫자)쓰고 '범위 복사'누르면 텍스트 박스에 자동 복사됨<br>
ㄴ'숨긴 메시지 포함' 체크하면 숨긴(눈 감김) 메세지도 같이 복사<br>
②태그 제거 : 상태창,추론 태그 일괄 자동 삭제<br>
③정리 : 과한 줄바꿈 깔끔하게 정리<br>
④위 내용 복사 : 현재 텍스트 박스에 적힌 내용 복사(클립보드로)<br>
⑤비우기 : 텍스트 박스 내용 전체 삭제<br>
⑥txt 저장 : 파일로 저장하기<br>
<br>
**ㅡ아이콘은 전부 개인화 설정 가능ㅡ**
<br><br>
<b>#캡처 (이미지 복사)</b><br>
①범위 지정하고 캡처 누르면 채팅 화면 보이는 그대로 이미지로 뽑아줌 (미리보기 = 결과물)<br>
②익명화 : 페르소나 이름은 기본으로 가려주고(바꿀 글자 설정 가능), 공통/캐릭터별 익명화 규칙 추가 가능 <-텍스트 복사엔 적용 안 됨, 이미지에만<br>
③캡처에 넣을 요소 : 상태창,이미지,선택지,표,접기,코드 등 넣을지 뺄지 체크로 선택, 미리보기에서 요소 꾹 누르면 바로 빼기<br>
ㄴ꾹 누르면 "~ 빼기 · 모든 봇" / "~ 빼기 · 이 봇만" 두 줄이 같이 뜰 때가 있음. 보통은 윗줄(모든 봇) 누르면 됨 (상태창·이미지처럼 복사기가 아는 종류라 어느 봇에서든 똑같이 빠짐)<br>
ㄴ아랫줄에 &lt;div.뭐시기&gt; 같은 외계어 뜨는 건 복사기가 종류를 못 알아본 그 봇 전용 블록임. 세상 모든 정규식을 다 알 순 없어서 "이 봇에선 이 블록 빼기"로 기억해 두는 거<br>
ㄴ외계어 한 줄만 뜨면 걍 그거 누르면 됨. 그 봇 캡처할 땐 앞으로 계속 빠짐 (되돌리긴 미리보기 위 ↶ 나 톱니바퀴 → 요소 목록에서)<br>
④표시 요소 : 봇/유저 각각 프사,이름,메세지 표시 여부 선택 (유저 이름은 기본 숨김)<br>
⑤출력 방식 : 한 장으로 이어 붙이기 / 메세지마다 따로, 원본 품질 / 경량 캡처<br>
⑥결과 : 클립보드 복사 or PNG 저장 (여러 장이면 폰은 ZIP 한 개, PC는 폴더 선택)<br>
<br>
<b>#편의 기능</b> <br>
①작성중인 메세지 태그제거 : 채팅 입력창에서 상태창,추론,이미지 태그 등등 제거<br>
②마지막 메세지 삭제 : 깡통,유저할거없이 제일 마지막 메세지 1개 삭제<br>
③삭제후 재생성 : 마지막 메세지 삭제 후 응답 재생성<br>
ㄴ캐시 우회(옵션) : 재생성 요청에 표식을 붙여 캐시된 답변 반복 방지, 표식은 채팅 기록에 안 남음<br>
ㄴ끈질기게 재시도(옵션) : 서버 에러 나면 정한 시간 동안 계속 다시 요청, 중단 버튼으로 멈춤<br>
④삭제 전 재확인(좆됨 방지) : 삭제 들어가는 모든 기능에서 한 번 더 물어봄 (기본 ON)<br>
⑤커스텀 버튼 : 원하는 기능을 골라 복사기 메뉴줄/입력필드에 내 버튼으로 추가<br>
ㄴ입력필드 아이콘은 위치·순서 개별 설정 가능<br>
<br>
<b>#메세지 정리</b> <br>
①메시지 숨기기/보이기 : 설정 범위 내의 메세지를 숨겨줌(눈 감김)<br>
ㄴ숨김 구간 확인 버튼 : 현재 숨겨진 메세지의 갯수와 범위 체크(1회성)<br>
②다중 메세지삭제 : 설정 범위 내의 메세지를 영구 삭제 (백업 필수!)<br>
<br>
<br><br>
<b>대필 기능</b> <br>
①대필 프롬프트(명령하기) : 여기에 적힌 내용을 대필시 AI가 참고함<br>
②임시 대필칸 사용시 : 기본 채팅 입력창밑에 임시 대필칸이 새로 생기고, 임시 대필칸에 적힌 내용은 ①과 함께 대필시 AI가 참고함<br>
③임시 대필칸 미사용시 : 기본 채팅 입력창에 적힌 내용은 ①과 함께 대필시 AI가 참고함<br>
<br>
<b>대필 프리셋</b><br>
①프리셋 저장(자동) : 대필 기본 지시문, 제외 지시문(부정 프롬프트), 대필 전용 프로필을 하나의 프리셋으로 저장.<br>
②프리셋 전환 : 프리셋 선택시 해당 설정으로 즉시 전환. 마지막 선택한 프리셋이 활성 상태로 지속 유지됨<br>
③프리셋 편집 : 연필 아이콘 클릭 후 이름 변경 또는 삭제 가능 (기본 프리셋 제외)<br>
④프리셋 복사 : 프리셋 선택 후 '현재 프리셋 복사' 선택시 동일한 내용의 새 프리셋 생성<br>
⑤순서 변경 : 프리셋 선택 후 '프리셋 순서 변경' 선택시 순서 조정 가능<br>
⑥사용할 프로필 : 실리 태번 페이지 새로고침/'사용할 프로필' 우측에 있는 새로고침 아이콘을 누르면 현재 유저의 '연결 프로필'을 연동해옴. 대필 요청시 설정된 '연결 프로필'기준으로 응답 요청함.(API,모델,메인 프롬프트 등)<br>
ㄴ대필 프로필 별도 설정시, 기본 3회까지 자동으로 재시도하며(서버 에러 방지) 중단 버튼 누를경우 즉시 원래의 프로필로 원복됨<br>
<br>
<b>퀵메뉴 / 플로팅 메뉴</b> <br>
①접근방식 : 선택한 설정대로 마법봉or입력필드에 퀵메뉴 생성됨<br>
ㄴ퀵메뉴는 누른 아이콘 위에 팝업 / 톱니바퀴 누르면 확장 설정으로 이동<br>
②표시할 섹션 : 퀵메뉴 내 상호작용 메뉴 취사 선택 가능<br>
③플로팅 메뉴 : 화면 위에 떠 있는 버튼, 드래그로 옮기면 위치 기억됨 (화면 밖으로 나가면 '버튼 위치 초기화')<br>
<br>
<b>#기타</b> <br>
①고화질 프로필 사진 : 채팅 화면에 뜨는 프사를 고화질로 나오게 함<br>
②입력창에 조절점 없애기 : 채팅입력칸 우측하단에 뜨는 입력박스 사이즈 조절 핸들 없애줌<br>
③입력창 안내문 : 채팅입력칸 내부에 있는 안내문구를 없애거나 원하는 문구로 바꿈(꾸미기 CSS 가능)<br>
④설정 저장 : 설정·프리셋은 브라우저와 실리 계정 양쪽에 저장돼서 같은 계정이면 다른 기기에서도 최근 설정이 따라옴<br>
⑤확장 설정 전체 초기화 : 복사기 설정만 싹 지우고 새로고침 (채팅·캐릭터·실리 설정은 안 건드림)<br>
⑥디버그 모드 : 추적 로그 활성 (개발 전용) <-이게 무슨뜻인지 모르면 킬 필요 저어어언혀 없음<br>
