깡갤 복사기
숨긴 메시지 포함
메세지 범위 입력 후 범위 복사 버튼을 클릭하면 클립보드에 자동 복사&아래 텍스트박스에 해당 내용이 삽입됩니다. 미입력시 자동으로 첫번째 메세지/마지막 메세지로 설정됩니다.
번호 범위를 지금 보이는 모습 그대로 미리보기로 띄웁니다. 비우면 첫/마지막 메시지로 채워집니다.
캡처 옵션 (보이는 그대로 이미지)
캡처는 메인 화면의 캡처(이미지) 모드에서 번호 범위를 넣고 누릅니다. 여기서는 익명화·숨길 요소·품질·출력 방식을 정합니다. 모든 설정은 저장됩니다.
익명화
공통공통 익명화 — 어떤 봇이든 항상 적용
지금 쓰는 페르소나 이름이 캡처 이미지에서만 오른쪽 글자로 바뀝니다. 페르소나를 바꾸면 새 이름에 적용되며, 채팅·텍스트 복사에는 영향이 없습니다.
봇별캐릭터별 익명화 — 지금 열린 봇에서만
현재 캐릭터: (캐릭터 없음)
왼쪽 칸의 글자가 캡처 이미지에서 오른쪽 칸의 글자로 바뀝니다(오른쪽을 비우면 그 글자를 지움). 실제 채팅 화면과 기록은 건드리지 않습니다. 긴 단어부터 먼저 바꿉니다.
자동 생성 이미지
실리 내장 이미지 생성·AutoPic 등으로 메시지에 붙은 그림을 같이 찍을지 정합니다. '빼고 캡처'를 고르면 그림이 원래 없던 것처럼 글만 이어서 찍힙니다.
캐릭터 에셋 이미지
캐릭터 에셋 확장(character-assets)이 본문에 끼워 넣는 그림(테두리·폴라로이드·시네마 등 모든 표시 방식)을 같이 찍을지 정합니다.
선택지
메시지 끝의 선택지 블록(choice 태그·선택 버튼·"선택지" 상태창 등)을 못 본 것처럼 빼고 찍습니다. 다른 상태창 안에 섞여 있어도 선택지 부분만 걷어냅니다.
상태창
상태창(stat·status·tracker·HUD·상태창 태그나 그런 이름의 상자, 정규식이 그린 상태창 프레임)을 빼고 찍을지 정합니다. 정규식 없이 태그만 벗겨져 글로 남은 상태창도 원문과 대조해 찾습니다. 봇마다 모양이 달라 못 잡는 경우엔 미리보기에서 꾹 눌러 빼면 됩니다.
표시 요소
봇
유저
봇/유저 메시지마다 프사·이름·메시지를 찍을지 정합니다. 프사를 끄면 자리는 비워 두고(화면과 같은 위치), 이름을 끄면 이름 줄이 접히고, 메시지를 끄면 그 쪽 메시지 상자가 통째로 빠집니다. 미리보기에 바로 반영됩니다.
이미지 품질
'원본 그대로'는 지금 화면에 보이는 픽셀 그대로 찍습니다. 폰이 느리거나 한 번에 많이 찍을 땐 '경량 캡처'를 고르면 됩니다(조금 흐릿한 대신 용량이 작고 빠릅니다).
출력 방식
'한 장으로'도 너무 길어지면(약 12,000픽셀) 자동으로 여러 장에 나눠 담습니다. 메시지 20개 이상이거나 예상 크기가 크면 캡처 전에 한 번 물어봅니다.
캡처 미리보기
요소를 꾹 누르면 빼기 메뉴
캡처에 넣을 요소 — 체크 = 넣음, 바로 반영
공통 항목(상태창·이미지·선택지·표 등)은 모든 봇에, 봇별 블록은 이 캐릭터에만 저장됩니다. 미리보기에서 요소를 꾹 눌러 빼도 같은 설정이 바뀌며, 상단 ↶ ↷ 로 되돌릴 수 있습니다.

체크 해제시 기본 입력창에 쓴 내용을 대필 지시문으로 사용합니다.
메시지 숨기기/보이기

숨긴 메시지는 AI가 인식하지 못하지만 채팅 기록에는 남아있습니다.

끈질기게 재시도
응답 요청이 실패(429 과부하·서버 오류·네트워크 끊김 등)하면 2~5초 쉬었다가 5분 동안 계속 다시 요청합니다.
실제로 응답을 기다리는 동안은 평소와 같은 토스트가 뜨고, 실패해서 쉬는 동안만 n회째 재시도 · 남은 시간이 표시됩니다. 쉬는 동안에도 입력창의 정지(■) 버튼이 유지되니, 정지 버튼이나 토스트의 [중단]을 누르면 즉시 깔끔하게 멈춥니다.
커스텀 버튼
원하는 동작을 고르고, 왼쪽 아이콘을 눌러 아이콘을 바꿀 수 있습니다. 버튼이 더 필요하면 '+ 버튼 추가'(최대 8개), × 로 지웁니다.
확장 내부: 복사기 메뉴줄 아래 아이콘 줄에 추가 · 입력필드: 채팅 입력창 옆에 아이콘 추가 · 퀵메뉴/플로팅 메뉴의 '커스텀' 섹션에도 자동으로 나타납니다.
삭제 전 재확인(좆됨 방지)
삭제나 재생성 기능을 실행할 때, 실수 방지를 위해 한 번 더 물어봅니다.
입력필드 아이콘 순서
    위에 있을수록 앞(왼쪽)에 놓입니다. 테마나 CSS 에 따라 실제 자리가 조금 다를 수 있습니다.
    기능을 켠 후 표시할 위치를 선택하면 됩니다.
    확장 내부: 복사기 메뉴줄 아래 아이콘 줄에 추가
    입력필드: 채팅 입력창에 아이콘 추가
    퀵메뉴 사용
    퀵메뉴를 활성화하면 채팅 화면에서 빠르게 복사기 기능에 접근할 수 있습니다.
    퀵메뉴 접근 방식
    마법봉: 화면 우측 하단의 Extensions 메뉴(🪄)에서 접근
    입력필드 아이콘: 채팅 입력창 옆에 아이콘 추가
    체크하면 오른쪽에 아이콘이 나타납니다. 그 아이콘을 누르면 접근 방식별로 아이콘을 따로 바꿀 수 있습니다.
    표시할 섹션
    체크 해제한 섹션은 퀵메뉴에서 숨겨집니다. '커스텀 버튼'은 편의기능에서 커스텀 버튼을 켜고 슬롯을 채워야 보입니다.
    플로팅 메뉴 사용
    화면 위에 떠 있는 둥근 버튼을 추가합니다. 버튼을 누르면 퀵메뉴와 같은 메뉴가 그 자리에서 열립니다.
    버튼은 손가락/마우스로 끌어서 원하는 위치에 둘 수 있고 위치는 기억됩니다.
    켜면 오른쪽에 아이콘이 나타납니다. 그 아이콘을 눌러 플로팅 버튼의 아이콘을 바꿀 수 있습니다.
    표시할 섹션
    체크 해제한 섹션은 플로팅 메뉴에서 숨겨집니다. 실제 기능은 퀵메뉴·소메뉴·입력필드와 모두 같은 것이고, 여는 방법만 다릅니다.
    버튼 위치 초기화
    버튼이 화면 밖으로 나가 안 보일 때 눌러 주십시오.
    고화질 프로필 사진
    프로필 사진을 고화질로 표시합니다.
    이 옵션을 이용하는 것보다 SillyTavern의 config.yaml 파일에서 thumbnails 섹션의 enabled 값을 true에서 false로 변경하는 게 여러모로 훨씬 좋습니다. 파일 수정이 어려운 이용자를 위한 옵션입니다. 구형 기기를 사용할 경우 페이지 로딩 후 몇 초간 기니피그 한마리만큼의 성능 저하가 발생하며, 그 이후로는 햄스터 꼬리털 세포만큼의 성능 저하가 있습니다.
    입력창에 조절점 없애기
    채팅 입력창의 크기 조절 핸들을 제거합니다.
    입력창 안내문
    채팅 입력창의 '메시지를 입력하거나 /? 도와주기 위해' 문구를 숨기거나 원하는 문구로 바꿉니다.
    테마·커스텀 CSS가 안내문을 억지로 띄워도 이 설정이 우선합니다. 대필 임시 지시칸의 안내문도 함께 적용됩니다.
    꾸미기 CSS 는 ::placeholder 안에 들어가는 속성만 적습니다(선택자 없이).
    디버그 모드
    문제 해결을 위해 콘솔에 자세한 로그를 출력합니다. 이게 뭔지 모른다면 키지 마십시오! 근데 켜도 크게 상관은 없습니다. 개미 더듬이 세포 하나만큼의 성능 저하가 발생합니다.
    업데이트
    확장 관리 창을 열지 않고 여기서 바로 깃허브 최신 버전을 받습니다. 업데이트 뒤엔 새로고침해야 적용됩니다. 깃허브에서 설치한 복사기에서만 동작합니다.
